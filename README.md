# Open Reference website

Public website for Open Reference, Canada’s open data reference layer.

## GitHub Pages

The site deploys automatically from `main` using the **Deploy Open Reference to GitHub Pages** workflow.

The static entry point is `docs/index.html`. The deployment workflow generates
`docs/styles.css` from the shared visual system in `app/globals.css`.

Contact links currently use `info@culturecreates.com`. Team names and roles
mirror culturecreates.com as of August 2026. The wording describes Open
Reference as an independent company backed by Culture Creates without implying endorsement by
the Canadian Open Data Society or any government.
